# Tianze Skills

A collection of custom AI coding-agent skills for GitHub Copilot, OpenAI Codex, and other LLM-powered tools.

## Skills

| Skill | Description |
|-------|-------------|
| [tianze-blog-digest](tianze-blog-digest-skill/) | Fetch and summarize the latest posts from curated AI/tech blogs into a structured digest report. |
| [tianze-llm-paper-scout](tianze-llm-paper-scout-skill/) | Recommend recent arXiv papers on AI/LLMs with emphasis on engineering usefulness over theory-heavy work. |
